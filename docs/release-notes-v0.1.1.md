## Prompter v0.1.1

投屏隐身提词器：共享屏幕 / 投屏时，稿件窗口**不进入画面**，跟着你说话自动滚动。

### 这个版本能做什么（相对 v0.1.0）

**新增：应用内更新。** 以后不用再回来下安装包了 —— 有新版本时软件自己会提示。

- 打开软件**约 3 秒后**自动查一次有没有新版本（不联网时就安静地跳过，不打扰你）
- 有新版时，顶栏下面出现一条 **`新版本 x.y.z 可用（当前 x.y.z）`** 的细横条
- 点 **[更新]** → 自动下载 → 自动安装 → 自动重启。全程不用管
- 不想现在更新就点 **[稍后]**，它不会再来烦你（下次启动会再查一次）
- 也可以手动查：**设置 → 更新 → 检查更新**
- 下载时底边有一条进度线；它不认识"下载了多少 MB"，只回答"**它还在动吗**"

### ⚠️ 已经在用 v0.1.0 的，这一版必须**手工装一次**

你现在装的 v0.1.0 **里面没有更新功能** —— 它不可能自己发现 v0.1.1。
所以这一次还是要下载安装包、双击、下一步。

**但从 v0.1.1 开始就自动了**：以后发 v0.1.2、v0.1.3，软件自己会弹提示、自己装完。
这一次是最后需要你动手的一次。

### 安装（Windows）

下载 **`Prompter_0.1.1_x64-setup.exe`**（6.91 MB）→ 双击 → 下一步。
装完开始菜单里就有「Prompter」。

- 按**当前用户**安装，**不需要管理员权限**
- 依赖系统的 WebView2 运行时；万一机器上没有，安装包会联网补一份
- 装的时候软件如果正开着，安装器会先关掉它、装完再自己启动
- 想卸载：Windows 设置 → 应用 → Prompter

### 更新包是**签名**的，装不上就是没验过

这条给内行看：软件下载到的更新包，在安装前必须通过 **minisign 签名校验**。
签名对不上（包里被塞了东西、或者签名与内置公钥不匹配）就**拒绝安装**，
而不是"装上了但没验"。⇒ 即使传输环节被人做了手脚，也装不进去。
