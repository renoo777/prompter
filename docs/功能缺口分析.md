# Prompter 功能缺口分析

> 调研日期：2026-10-05
> 方法：`feature-gap-analysis` 五步法（定品类结构 → 成熟品功能全集 → **失效模式** → 分层对照 → 按致命度排序）
> 配套：`docs/产品分析-竞品调研.md`（定位与定价视角）。**那篇回答"我们凭什么不一样"，这篇回答"下一轮该补什么"。**

---

## 1. 一句话核心判断

> **成败不在"再加几个功能"，在"语音跟随会不会跟丢、跟丢了能不能自己爬起来"。**
>
> 全品类的第一弃用原因不是缺功能，是**跟读失准**——PromptSmart 的语音跟随被 38% 的评论提及，其中**只有 16% 是正面评价**（lost sync / erratic scrolling / crash）。而我们恰好在这件事上有 112 个单测焊住。
>
> 推论：**下一轮不该做功能加法，该把"跟读稳"变成用户能看见的承诺 + 做分发。**

---

## 2. 品类结构：提词器的四个段落

提词器不是一个功能集合，是四段流水线。**v0.x 通常把「核心」做完了，两端是空的。**

| 段 | 职责 | 本产品 | 状态 |
|---|---|---|---|
| **① 入口（拿到稿）** | 从哪把稿子弄进来 | txt/md/**docx**/**pptx 备注**/拖入/粘贴/历史库/稿内查找 | ✅ **最完整的一段**（竞品普遍只有 txt/md） |
| **② 核心（推进）** | 谁决定稿子往下走 | 语音跟随 / 匀速 / 手动 / 滚轮接管 | ✅ **最深的一段**（112 单测） |
| **③ 出口（说了就看不见）** | 投出去之后稿子还在不在 | Windows 投屏隐形（实测）/ macOS（未验）/ 穿透 / 托盘 | ⚠️ **一半有证据，一半没验** |
| **④ 闭环（下次还能用）** | 稿件留存与复用 | 历史库 / 配置迁移 / **安装包 / 自动更新（缺）** | 🔴 **空的一段** |

> **判据：②③ 是我们的护城河，① 已经超出竞品，④ 是空的。**
> ④ 正是 §5 里"致命档"唯一那条的所在。

## 3. 成熟品功能全集（第 2 步）

跨 9 家产品交叉比对，**反复出现 = 品类共识（table stakes）**；只在一家出现但被称赞 = 设计洞察。

### 3.1 品类共识功能（出现 ≥4 家）

| 功能 | 本产品 | 判定 |
|---|---|---|
| 可调滚动速度 | ✅ | 共识 |
| 字号 / 行高 / 字距 / 对齐 | ✅ 全套最全 | 共识（我们最好） |
| 悬浮在别的 App 之上 | ✅ | 共识（隐形赛道的入场券） |
| 透明度可调 | ✅ | 共识 |
| 语音跟随 | ✅ **离线** | 共识，但**是全品类口碑最差的功能**（见 §4） |
| 手动 / 遥控翻页 | ✅ 全局热键 | 共识 |
| 深浅色主题 | ✅ | 共识 |
| 导入 txt / Word | ✅ docx 正文 | 共识 |
| 脚本云同步（多设备） | ❌ | 共识（我们缺，见 §5 致命档） |
| 镜像模式（beamsplitter 玻璃） | ❌ | 共识（**但对我们无意义**，见 §6 减法建议） |

### 3.2 设计洞察（只在一家出现但被称赞）

| 功能 | 谁有 | 为什么有价值 |
|---|---|---|
| **pptx 取备注页**（而非幻灯片正文） | **本产品** | 讲稿顺序天然对应页序；目前没见到第二家做对 |
| **"0.00% 像素差"客观验证** | **本产品** | 无人证明过；见配套报告 §3.2 |
| **静音看门狗 + 电平心跳** | **本产品** | 麦克风不收音时界面不假死，且**自己说出来** |
| 语音 Glide 不漂移（0 drift） | Teleprompter.com | 明确对标"5 分钟零漂移"，说明这是行业痛点 |
| 违禁词/合规检测 | 快提词等电商向 | 带货场景刚需（"绝对最低价"未扫出差点被限流） |
| 字数 / 时长预估 | ShareSpeak | 卖"预计讲多久"，是付费点也是决策辅助 |

### 3.3 中文市场的功能长板（竞品清单里普遍缺）

搜到的中文提词器（创作猫 / 快提词 / 提客 / 提词器大师 / 小熊 / 野兽 / 小白 / 芦笋 / 提词匠）**全部是手机端或"提词器顺带做"的附赠功能**：

- ❌ 无一有**投屏 OS 级隐形**（它们只做到"悬浮窗"+"不录进成片"）
- ❌ 无一有**离线语音跟随**（云端延迟 0.3–1.5 秒，**这是他们被吐槽的第一名**）
- ❌ 无一支持 **docx/pptx 批量导入**
- ✅ 有的是**违禁词检测**（电商刚需）
- ✅ 有的是**字幕/视频提取台词**（小红书提词器能"从视频/音频提取台词"）

> **判据：中文提词器市场是"一堆凑不齐功能的顺手小工具"，没有一个像样的对手。** 这解释了为什么我们功能上全面领先却仍然没被市场发现——**问题不在功能，在"没人知道 + 装不上"。**

## 4. 失效模式调研（第 3 步 · 本节最重要）

### 4.1 硬数据：语音跟随是全品类最差的功能

来源：Teleprompter.com 对全品类 **5600+ 条 App Store 评论**的自家分析（注意：它自家也是竞品，但数字是第三方可复核的量级）

| 指标 | 数值 |
|---|---|
| PromptSmart 评论中**提到语音跟随**的比例 | **38%** |
| 其中**正面**评价比例 | **仅 16%** |
| 负面关键词 | lost sync / erratic scrolling / crashes |
| Teleprompter.com 自家 VoiceGlide 的**正向**占比 | **87%** |

> **⚠️ 这条是本报告最重要的发现。**
> 语音跟随是这个品类的**核心卖点，也是最大差评来源**。用户不是嫌它没有，是嫌它**不可靠**。
> 竞品的解法是"宣传自己不漂移"（87% 正向），而我们的解法更硬——**用确定性算法（丢掉阿拉伯数字、保留汉字数字、LCS 对位）+ 112 个单测**。
> **但用户看不到测试。** 见 §5 的 P0-2。

### 4.2 中文市场 AI 眼镜提词器的四条翻车坑

AI 眼镜提词器（雷鸟 iO / INMO GO3 / Rokid）2026 年翻车，转载的复盘帖（什么值得买）总结得极准，直接适用于桌面提词器：

| 坑 | 用户原话/现象 | 对我们的映射 |
|---|---|---|
| **① 跟读会卡（最致命）** | "你演讲时一旦自己多说了一句废话，眼镜里的词就卡住跟不上了" ——**脱稿发挥的每一句，系统都当成"还在讲上一页"** | ✅ 我们的"无关语音不应移动光标"单测正是解这个。**但要能证明。** |
| **② 漏光** | "特定角度下侧前方能看到绿光……注意，是不明显，不是没有" | 对应我们：白色文字在亮背景下看不清（**竞品 Chrome 版 0 星差评也提到这条**） |
| **③ 位置不可调** | "字幕位置不能移动"、"提词器太偏上 一直盯着看不行，上台演讲看一次翻一次白眼" | ✅ 我们有位置/锚点/对齐排版，**这一项我们完胜** |
| **④ 体验割裂** | "APP 端是可以看到识别没有什么问题，但是不会显示" | 对应我们：**改完代码必须重启才能看到**（交付必说重启） |

**坑①的原理解释最值钱**：跟读失准的根因不是"识别慢"，而是**用户实际说的话 ≠ 稿子下一句**——多一句废话、少跳一句、重复一句，系统就卡住。
> **这是竞品普遍没正面解决的问题，也恰好是我们在做对位算法时处理过的东西。** 把它做成"看得见的承诺"，比做十个新功能都值。

### 4.3 其他高频失效原因（跨平台共识）

| 原因 | 证据 | 我们的状态 |
|---|---|---|
| **免费版字数额限** | Reddit 最高赞吐槽："free tier stops at 300 words" | ✅ 无限 |
| **水印** | Reddit 大量"拍到一半发现有 logo" | ✅ 无水印 |
| **付费墙挡在开始按钮前** | Reddit 专项吐槽（"load 完了、稿子也粘了，Start 按钮要付费"） | ✅ 免付费 |
| **要求登录** | 隐私顾虑，稿子常含机密 | ✅ 无登录、纯本地 |
| **不稳定 / 长录崩** | "Try to record 20+ min… App freezes. Video lost." | ✅ 已测 177s/15x 实时/0.99 倍平直 |
| **镜像功能被事后收费** | 某 app 把 mirror 从免费挪到付费，老用户没被 grandfathered ⇒ 一个月内 11 条一星 | ❌ **我们没有镜像功能 ⇒ 天然规避**（见 §6） |
| **导入失败/白屏** | 竞品 0 星差评："importing scripts is not intuitive or sometimes fails (blank screen)" | ✅ **明说原因与出路** |

## 5. 分层对照与缺口表（第 4 步）

分层框架用"提词器专用"的一套：入口 / 推进 / 出口 / 闭环 / 信任。

| 层 | 成熟品有 | 本产品现状 | 缺口 | 致命度 |
|---|---|---|---|---|
| **入口** | txt/md/docx/pdf、**云同步、粘贴**、拖入 | txt/md/**docx**/**pptx 备注**/拖入/粘贴/历史库/查找 | PDF 导入 | 🟢 锦上添花 |
| **入口** | **多设备云同步** | ❌ 只有导出/导入迁移包 | **无自动同步** | 🔴 **致命** |
| **推进** | 语音跟随 / 匀速 / 遥控 | 全部有，且**离线** | 无 | ✅ |
| **推进** | **跟读稳定性可被用户感知** | 算法有 112 单测，**但界面零反馈** | **无"跟读状态"可视化** | 🔴 **致命** |
| **推进** | 字数/时长预估 | 有 `wpm_ref` 但**已死**（见配套记忆） | **死设置** | 🟠 每天别扭 |
| **出口** | 投屏隐形 | Win ✅ 实测 / macOS ⚠️ 未验 | **macOS 真机** | 🔴 **致命** |
| **出口** | 移动端 App（手机当提词器） | ❌ | 二设备/移动端 | 🟠 每天别扭 |
| **闭环** | **安装包 / 商店上架** | ❌ `--no-bundle`，得"知道 exe 在哪" | **无安装包、无更新** | 🔴 **致命** |
| **闭环** | 自动更新 | ❌ | 同上 | 🔴 致命 |
| **信任** | 隐私（无登录/本地） | ✅ 纯本地 | — | ✅ |
| **信任** | **能自证隐形** | ✅ 脚本有 0.00% 像素差 | **用户看不到** | 🔴 **致命**（详见 P0-1） |
| **信任** | 显式失败 | ✅ 麦克风/导入/私有 API 都如实说 | — | ✅ |
| 布局 | 亮暗主题 / 字体 / 位置可调 | ✅ 全部有 | — | ✅ |

**🔴 致命档有 5 条，全都不是"加功能"，而是"补分发 + 补可见性 + 补同步"。**

## 6. 优先级表（第 5 步 · 按"缺了会怎样"排序）

### 🔴 致命档 —— 不补，1–2 周内被弃用（或长期停在"自己知道好"）

| # | 缺口 | 为什么致命 | 成本 |
|---|---|---|---|
| **F1** | **装不上 / 没有更新** | 竞品全部有商店或官网分发。**用户第一道门是"我能不能装"，不是"它好不好用"**。`--no-bundle` 意味着无卸载项、无开始菜单、无自动更新 | **极低**（`npx tauri build --bundles nsis` 已实测 6.1MB） |
| **F2** | **跟读稳不稳，用户看不见** | 全品类第一差评来源（38% 提及 / 16% 正面）。我们有 112 单测**但界面零表达** ⇒ 用户只能凭感觉判断 ⇒ 感觉=不可靠 | **低**（已有 `对位引擎`/`电平`/`看门狗`三处状态可接） |
| **F3** | **无自证隐形** | 全部竞品只给宣称。`verify-stealth.py` 能给 0.00% 像素差，**但只有开发机能跑** ⇒ 唯一不可复制的资产没变成产品 | **低**（把脚本结果做成 UI 一张卡） |
| **F4** | **第二设备无同步** | 竞品普遍 2–3 设备/许可。团队/夫妻双机、手提+台式只能手动导入导出 | 中 |
| **F5** | **macOS 未上真机** | 唯一可能推翻"双平台"定位的项（详见配套报告 §4）。**在验之前它不是产品，是设计意图** | 需一台 Mac |

### 🟠 每天别扭档 —— 每次用要绕一下，累积成不用的理由

| # | 缺口 | 判断 |
|---|---|---|
| M1 | `wpm_ref` 死滑杆 | 拖了没后果 = 持续的信任损耗。**三个选项待拍板**（接回剩余时间／删掉／留着） |
| M2 | 补 PDF 导入 | 品类共识里我们唯一的缺口（docx/pptx 都有了，PDF 反而没有） |
| M3 | 字数/时长预估 | 竞品在卖这个（"预计讲多久"是付费点），我们有半成品（死掉的 wpm_ref） |
| M4 | 移动端/手机当提词器 | 场景真实（"低头方案"是竞品上限），但要求 Mac/Win 之外的第二套工程，非当前重点 |
| M5 | 违禁词/合规检测 | **仅当目标人群是带货主播时才是刚需**。对我们（会议汇报为主）不成立，**不做** |

### 🟢 锦上添花档

- **镜像模式（beamsplitter 玻璃）** —— ⚠️ 见 §7 减法建议，**建议不做**
- 长录多轨导出、字幕生成、AI 脚本写作 —— 那是 BIGVU/Teleprompter.com 的订阅制地盘，**不做**
- 多语言 UI —— 除非有明确出海诉求

## 7. ⚠️ 明确建议**不做**的（防"功能加法"陷阱）

本节是本报告的判断所在，不是清单。

1. **❌ 镜像模式**（beamsplitter 玻璃）—— 品类共识里唯一**我们该主动放弃**的。理由：它是**硬件提词器配套功能**（Teleprompter Pro / Elgato Prompter / 淘宝百元级玻璃提词器的生态），而我们的场景是**"投屏给别人看"**，用户面前**没有分光镜**。做了只是让功能表更长。
2. **❌ 内置录像 / 剪辑 / 字幕** —— 那是 Teleprompter.com 与 BIGVU 收订阅费的正当性来源。我们的价值是"稿子不外泄"，一旦开始吞视频工作流，就要在他们的主场打。**用户为"隐形"付一次钱，不会为"隐形"按月付**（配套报告 §3.2）。
3. **❌ 往"AI 实时答问题"走**（Interview Copilot / Final Round AI 路线）—— 那是另一个产品、另一个舆论区（Amazon 明令禁止 GenAI 工具）、另一套定价（$49–150/**月**），而且他们已经抢走了"愿意付大钱"的人。
4. **❌ 追"功能更多"** —— 中文市场一堆对手（创作猫/快提词/芦笋/小熊/野兽…）功能表都比我们长、比我们全（还带违禁词检测、字幕提取），**我们赢在深度不在广度**。比广度永远输：他们的上游是剪辑工具和电商 SaaS。
5. **⚠️ 警示：失效模式里没有一条指向"功能太少"。** 全部指向**不可靠 / 装不上 / 被订阅绑架**。这正是技能里说的"功能加法陷阱"——**正确的动作是做减法（聚焦）+ 做分发，不是补功能。**

## 8. 推荐动作

### P0（不补就会被弃用，且都**不是**新功能）

1. **F1 出 NSIS 安装包 + 分发**——门槛最低、影响最大。同时补"版本/更新"提示。
2. **F2 把"跟读稳"变成界面能说的话**——把 `对位引擎匹配/电平/看门狗` 三处已有的状态接进顶栏状态槽或正文区（如"跟读中 · 已对齐"），让用户看到确定性。**这直接对冲全品类第一差评。**
3. **F3 把隐身验证做成 UI 一张卡**——"自检"按钮 → 跑锚点对比 → 报"共享画面中未出现本窗口（0.00% 像素差）"。**竞品无一家能这么干。**
4. **改 README 的 macOS 措辞**（"✅ 同左" → "尽力而为"）——10 分钟，对外诚实度提升，10 分钟的事。

### P1（产品化/闭环）

5. **F4 第二设备同步**（或至少"局域网发现 + 一键推稿"）
6. **M1 处置 `wpm_ref`**（等拍板）
7. **M2 补 PDF 导入**（补齐品类共识最后一块）
8. **M3 字数/时长预估**（与 M1 一起做）
9. **重拍 `shots/` 状态图 + 同步断言**——现有 `check-state-shots.py` / `make-state-sheet.py` 断言的是改版前界面，**给 ✅ 但什么都没验**；失效门槛比没门槛更危险

### P2（观察，不承诺）

10. **F5 macOS 真机验证**（取决于是否还有 Mac 可用；无则走"降级为尽力而为"）
11. 商业化预研：若做，**一次性买断 $15–60 / ¥48**，不订阅

## 9. 三个需要老大拍板的问题

1. **F2 的表达形式**：跟读状态是放**顶栏状态槽**（占位、但对齐判据要求"一槽一生产者"）、放**正文区块**，还是只在**跟读异常时**才出现？
2. **M1 `wpm_ref`**：接回剩余时间 / 删掉滑杆 / 留着？
3. **是否做"减法"**：确认 §7 的 5 条"不做"（尤其**镜像模式**——品类共识但对我们无意义，主动放弃是否 OK）。
