## Prompter v0.1.0

投屏隐身提词器：共享屏幕 / 投屏时，稿件窗口**不进入画面**，跟着你说话自动滚动。

### 这个版本能做什么

- **隐身** —— 会议共享时稿件窗口不进画面（Windows 走系统级窗口排除，本机实测投屏画面像素差 **0.00%**，即完全没进画面）
- **跟随** —— 离线中文语音识别，说到哪、滚到哪。不联网、不上传音频
- **稿件管理** —— 多稿件 + 分组 + 导入导出
- **穿透** —— 鼠标可以直接穿过提词窗点到下面的软件，只留一小条控制栏可点

### 安装（Windows）

下载下面的 **`Prompter_0.1.0_x64-setup.exe`**（6.25 MB）→ 双击 → 下一步。装完开始菜单里就有「Prompter」。

- 按**当前用户**安装，**不需要管理员权限**
- 依赖系统的 WebView2 运行时；万一机器上没有，安装包会联网补一份
- 想卸载：Windows 设置 → 应用 → Prompter
