## 已验证 / 未验证

**已验证**

- ✅ **Windows 投屏隐身**：真实飞书会议中确认窗口不进入共享画面；
  另有自动化验证脚本，用「隐藏窗口锚点 + 切换前后抓屏对比」给出客观证据 ——
  不仅证明前后有变化，而是证明**隐身开启时窗口对捕获画面的贡献为零**
  （Windows 11 build 26200 实测：开启隐身时的捕获画面与「窗口完全隐藏」的
  显著差异像素为 **0.00%**；不隐身时同一区域 92.9% 像素发生变化）。
  同一次测量还反解出窗口不透明度 α = 0.942，与配置的 0.94 一致，
  排除了「透明度被算两遍」。见「自动化验证」一节。
- ✅ **本地中文 / 中英混说识别**：用模型官方 `test_wavs` 离线跑通，
  4 段音频共识别出 61 个汉字，含模型加载总耗时 9.6 秒（约实时）。
  实测输出示例：`昨天是 MONDAY ｜ TODAY IS LIBR THE DAY AFTER TOMORROW是星期三`、
  `这个是频繁的啊不认识记下来 FREQUENTLY频繁的`。

   校准 `min_score` / 前后窗口大小。
6. **第二设备通道** —— 稿件跑在手机/iPad 上、局域网同步、电脑屏幕无提词器窗口。
   这是**唯一不依赖任何系统 API 的隐身方案**，也是 Linux 上唯一可行的方案。
   开源竞品里 `f/textream`、`Storm-Teleprompter-Plus` 都验证过这条路。
7. 云端识别接入（如果本地准确率在专业术语上不达标）。
